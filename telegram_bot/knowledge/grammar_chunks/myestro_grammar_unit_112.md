UNIT
112
If I had... If we went...
1. Unreal Situations (Haqiqatga zid holatlar)
Hozirgiz amon haqidagapirganda,mavjudbo'lmaganyokitasavvurdagi shartlarni
ifodalash uchun ishlatiladi:
[Image: Person dreaming about having wings to fly]
• Dan likes fast cars but he is poor.
• If he had the money, he would buy a fast car.
(Uning puli yo'q, lekin bo'lganida sotib olgan bo'lar edi).
IF PART (Condition) MAIN PART (Result)
IF + PAST SIMPLE WOULD + VERB
(had / knew / were / lived) (buy / tell / be / go)
2. Using "WERE" for all persons
But urdagigaplarda I / he / she / ituchunhamwereishlatish rasmiy va to'g'ri
hisoblanadi:
• If I were you, I wouldn't go there.
• If he were here, he would help us.
• If it weren't raining, we could go for a walk.

112
Exercises (Homework)
112.1 Fe'llarni to'g'ri shaklda qo'ying (Past Simpleyoki
Would).
1. If I
had (have) the money, I would buy a fast car.
2. If you
didn't go (not/go) to bed so late, you wouldn't be so tired.
3. I
(help) you if I (can).
4. If I
(be) you, I wouldn't wait any longer.
5. We
(go) out if it (not/rain).
112.2 Vaziyatga qarab gaplarni "If I..." bilan tuzing.
1. I don't know her number, so I can't phone her.
→ If I knew her number, I could phone her.
2. I have to work tomorrow, so I can't go to the party.
→ If I didn't have to work tomorrow, I could go to the party.
3. I'm not tired, so I'm not going to bed.
→
4. I don't have enough money, so I can't buy a new car.
→
💡
Eslatma: "If I were you..." iborasi maslahat berish uchun ishlatiladi (Sizning
o'rningizda bo'lganimda...).
