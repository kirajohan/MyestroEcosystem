UNIT
111
If we go ...
Shart gaplar (Conditionals)
1. The "IF" Structure (Agar...)
"If" ishtiroketgangaplarbirorishningsodirbo'lishi uchun ma'lum bir shartni
bildiradi.
If + Present Simple, + will / won't
• If we go by bus, it will be cheaper.
• If you don't hurry, you will miss the train.
2. Punctuation (Vergul qoidasi)
Xuddi" when"kabi,agargap"if"bilanboshlansa,o'rtada vergul ishlatiladi.
• If you see Ann tomorrow, can you ask her to phone me?
• Can you ask Ann to phone me if you see her tomorrow? (Vergul yo'q)
3. IF vs WHEN
• IF: Sodir bo'lishi aniq bo'lmagan holatlar uchun (Maybe).
• WHEN: Sodir bo'lishi aniq bo'lgan vaqtlar uchun (Sure).
